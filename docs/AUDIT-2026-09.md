# Audit — September 2026 (findings & resolution)

**Scope:** `claude/tasks-planning` @ `a740592` (PR #3), about 16k lines.
**Method:**
- Typecheck, production build, `npm audit` / `npm outdated`.
- Four parallel code reviews: security & data, domain logic, views, shell/components.
- A real-browser smoke test (Playwright, 1440 px and 390 px, axe-core).

Fixes were made on `claude/brave-allen-sbut3y`, then re-verified by an independent end-to-end run: 28 scripted checks, all routes, both widths.

**Before → after:**
- `npm audit`: 1 critical and 5 high → 0.

- Tests: none → 79.
- axe serious/critical: about 300 → 0.
- Console errors: 0 → 0.
- Horizontal overflow: 4 routes → 0.

| # | Finding | Resolution |

| 2 | Supabase: open sign-up; RLS allowed any signed-in user to do anything | ✅ Invite-only login (`shouldCreateUser: false`). Access requires an `app_users` row (`is_app_user()`) on every policy. | 3 | Demo mode: unauthenticated server actions mutated shared server memory | ✅ Actions refuse writes in demo mode; with Supabase they require an authorised viewer. Inputs are validated with zod. Actions return `{ok, error}`. |
| 4 | Workload capped at 100 %, so overload was never detected | ✅ Charge = demand ÷ capacity. Demo data resized to the six-person team (≈70–80 % average load, 2 members over capacity). |
| 5 | A cleared date field produced NaN and broke the whole Gantt | ✅ Date parsing is NaN-proof, derivations skip bad dates, the UI and store reject empty or invalid dates. |
| 6 | Drawer/modal focus: Escape active for the whole session; focus jumped to ✕ on each keystroke | ✅ One overlay stack for modal, drawer, palette and popovers: focus trap, top-only Escape, focus return, scroll lock, inert background. |

## Open / deferred

- **TypeScript 7.0:** the app builds with it (typecheck 1.5 s vs 7.9 s), but typescript-eslint doesn't support TS 7 yet. Upgrade when it does.
- **Supabase write concurrency:** there is no `updated_at` optimistic locking and no Realtime refresh. The last write wins across users.
- **Demo mode:** a project that exists only in the browser returns HTTP 200 ("Projet introuvable" until the store hydrates) rather than 404. This is inherent to localStorage data.
- **Per-route `<title>`s.**
- **Minor visuals:** empty band under two dashboard KPI cards; the calendar "+N" sits close to the next week's dates.
